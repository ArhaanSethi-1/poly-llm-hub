# Seed model catalog

`seed_models.json` supplies the default 15 entries when the local catalog has no models and has not been seeded before. Each row keeps its provider ID, context/output limits, published pricing URL, model metadata source, and provenance. Ollama entries cost no API tokens; the user still needs Ollama installed, running, and the model pulled.

`rank_score` is the published LMArena text style-control overall `index_score` where the exact model family and tested configuration can be matched. `rank_source` records the tested variant and snapshot date. This is a human-preference leaderboard measure, not a guarantee of performance on an individual task. Entries with no comparable published score use `null`; the UI sorts scored rows first and labels unscored rows clearly. No score is inferred from pricing or context length.

Provider model, context, pricing, and Arena data can change. Every Arena score points to the Arena dataset; model metadata and pricing fields link to provider documentation and include a checked date. `benchmark_scores` can store additional public benchmark values separately with source, variant, unit, and check date. Review found the two previously imported MIZAN values came from `mt_bench.jsonl`, which MIZAN labels Persian MT-Bench and describes as translated/rewritten Persian dialogue. Because those scores are not a broad English benchmark comparable to Arena, they were removed from the seed entries rather than shown as another overall ranking. See the pinned [MIZAN benchmark dataset](https://huggingface.co/spaces/MCINext/mizan-llm-leaderboard/blob/352d5dc71e80ebaf27328fb3682b79b2bdfdaf18/leaderboard/boards_data/mt_bench.jsonl) and its [dataset description](https://huggingface.co/datasets/MCINext/persian-mt-bench). Future scores must document language and task domain before display. Refresh the static seed with provider documentation before a release when current model IDs or prices have changed. Existing catalogs are never refreshed or overwritten by this file.

## Bundled pricing refresh

`pricing_table.json` is a release snapshot derived from the seed models. The user can manually apply it from the catalog page. The app does not fetch prices from provider APIs. A refresh matches the exact connection and model ID and preserves custom pricing that uses a different source URL.

## Direct browser calls

Direct Connection is enabled only for the built-in Anthropic Messages connection. The UI requires Anthropic's documented `anthropic-dangerous-direct-browser-access: true` request header; organization settings such as Zero Data Retention or Compliance API may still reject browser-origin calls. Its key stays in this browser's localStorage, and Chat/model discovery calls go straight to Anthropic. Direct mode is not offered for OpenAI, Gemini, xAI, DeepSeek, or Ollama in this release because browser CORS/auth behavior is not verified and supported here. Use Local Proxy for those providers and for Anthropic Compare mode. See [Anthropic authentication](https://platform.claude.com/docs/en/manage-claude/authentication).
