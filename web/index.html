History is off by default. When enabled, prompts, responses, model IDs, usage, latency, errors, ratings, and preferred-answer choices are saved locally in history.jsonl. Turning it off stops future saves; use Clear history to remove existing records. Saving a prompt set separately stores those test prompts in your local catalog.

Encryption uses AES-GCM with a key kept in the OS credential store. Decryption stays in Python for viewing and exports. Switching this setting migrates every existing history row after confirmation. Exports remain readable JSONL/CSV. Install requirements-history-encryption.txt to enable this option.

Filters apply to the saved model and prompt comparison summaries only, and last for this page session. Blank thresholds are inactive; when a threshold is active, rows without that measurement are excluded. Average cost uses only runs with estimates. Filtering does not change saved records or create a model ranking.
